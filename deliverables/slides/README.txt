Civic Services Surveillance & Monitoring — Dataset Presentation
================================================================

Contents:
  presentation.tex   LaTeX (Beamer) source
  presentation.pdf   Pre-compiled 17-slide PDF (ready to view/present as-is)
  images/            21 sample images (3 per class), annotated with the actual
                      training bounding boxes drawn in green, sampled directly
                      from this project's unified training dataset.

To recompile from source (optional, PDF is already included):
  pdflatex presentation.tex
  (requires a LaTeX distribution with the beamer, hyperref, booktabs packages)

Every dataset source cited in the slides is a real, working link to its
Roboflow Universe page (see the per-class slides). See DATASETS.md and
dataset_origin_report.txt in the parent project folder for the full source
list and India/non-India origin notes this presentation summarizes.
